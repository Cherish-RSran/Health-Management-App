# 家庭健康档案 · 安卓本机版 开发文档

> 面向开发者的工程手册：框架、技术栈、目录结构、部署（打包）方式与其他开发信息。
> 产品定位、与小程序差异、合规红线见 `README.md`。

---

## 1. 架构总览

本子项目是「家庭健康档案」的**安卓单机版**：同一套业务逻辑，把云端微服务换成同机实现，数据全部存本机、不联网。

```
Vue 3 SPA (src/)  ──import──>  server/actions + lib  ──调用──>  core/localdb (IndexedDB)
        │                                                        │
   Capacitor WebView                                       无网络：所有读写走本地
        │
   Android 原生壳 (android/)  ──gradle 打包──> APK
```

- **业务逻辑与云端小程序是同一份代码**，不是重写：`cloudfunctions/api/actions/*` →（`convert-server.js`）→ `src/server/actions/*`。
- **数据存本机**：用 `IndexedDB` 复刻了云数据库同一套 API，业务 action 无感切换。
- **无后端、无网络**：开飞行模式 App 照常运行。

| 类别 | 选型 |

│   ├── styles/                 # 由 wxss 转换而来（生成物）

> `src/server/` 与 `src/styles/` 是**生成物**。改业务逻辑请改云端小程序，再重跑脚本同步；改样式改 `miniprogram/**/*.wxss` 后重跑 `convert-styles.js`。

## 4. 前端要点

### 4.1 自绘 UI 原语
微信原生控件在 H5 里没有对应物，由 `App.vue` / `ui.js` 自绘：tabBar、导航栏、toast、modal、actionSheet。观感接近但不像素级一致（最明显：日期选择变成**系统日期选择器**）。

### 4.2 字段驱动表单 `FormSheet.vue`
Contract 与小程序一致：`FORMS` 对象描述表单（`fields` 含 `k/label/type/options/placeholder/hint/required`），类型 `text/textarea/number/date/chips/multi`。前端与小程序共用同一套字段定义即可对齐。

### 4.3 路由与登录
- 路由表在 `router/index.js`，`/login` 是安卓独有（小程序无登录页）。
- 首次启动停在 `/login`：可「登录 / 注册（手机号+密码）/ 跳过，仅本机使用」。
- 登录后 token 存本机；`server/lib/app.js` 的 `resolveToken()` 在内核层把 token 换成 `user_id`。**业务 action 只认 `ctx.openid`**，所以加账号体系没动任何业务逻辑。

## 5. 本地存储 `core/localdb.js`

- 用 `IndexedDB` 复刻云数据库的查询 API（`where`/`orderBy`/`limit`/`skip`/`count`/命令操作符），业务 action 无感。
- 库名 `family_health_db`，位于 App 私有目录；**卸载 App 会一起清掉**。
- `server/local.js` 是本地数据访问适配层（对应云版的 `query.js` 注入）。
- 敏感字段加密：浏览器无 WebCrypto 同步 AES，改用 **RC4 流密码 + 本机密钥**，目的仅是**避免明文落盘**，不是对抗拿到整机的攻击者。
- 无测试注入入口（原 `resetInstance` 已随测试代码移除）。

---

## 6. 业务逻辑层 `server/`（生成物）

- `actions/*.js`：与云端 `cloudfunctions/api/actions/*` 同一份，由 `convert-server.js` 转换（CommonJS → ESM，注入的 `db` 换成 IndexedDB 实现）。**行级未改**。
- `lib/app.js`：`createApp` + `resolveToken` + 分发，对应云端 `lib/app.js`。
- `lib/pwd.js`：PBKDF2-HMAC-SHA256（纯 JS 同步实现，与云函数版同一份），10000 轮；改它必须两端同步。
- `actions/index.js`：`reg()` 注册路由表，前端用 `api.call('命名空间.动作')`。

> 新增/修改业务功能：**改云端小程序**，重跑 `npm run gen:server` 即同步到本工程；不要直接改 `src/server/`。

## 7. 代码同步机制

| 源（手写，在 `apps/miniprogram-app`） | 派生（生成，本工程） | 脚本 |
|---|---|---|
| `cloudfunctions/api/actions/*` + `lib/*` | `src/server/*` | `npm run gen:server`（`convert-server.js`） |
| `miniprogram/app.wxss` + `pages/*/*.wxss` | `src/styles/*` | `node scripts/convert-styles.js` |
| `miniprogram/utils/constants.js` | `src/core/constants.js`（ESM 镜像） | **手动镜像**（CommonJS→ESM） |

`convert-server.js` / `convert-styles.js` 路径已指向 `../miniprogram-app/`（曾因深度分组遗留旧路径导致生成失败，已修）。

## 8. 样式转换 `convert-styles.js`

只做三件事（`src/styles/`）：

| 原文 | 转换后 |
|---|---|
| `28rpx` | `calc(28 * var(--rpx))`（`--rpx = 100vw / 750`，与小程序 750rpx=屏宽 同一套） |
| `page { ... }` | `:root { ... }` |
| `view / text` | `*` |

`npm run build` 的 Vite 会打包这些 CSS；同源样式可验证与小程序一致。

## 9. 构建与打包

### 9.1 仅 Web 预览 / 构建
```bash
npm install
npm run dev          # 浏览器预览 http://127.0.0.1:5173
npm run build        # 产出 dist/（Web 包）
npm run preview      # 静态预览 dist/
```

### 9.2 打包 APK（一键）
```bash
npm run apk
```
脚本流程：自检 JDK/Android SDK → `npm run build` → `npx cap sync android` → Gradle 打包 → 复制 APK 到 `家庭健康档案-debug.apk`。

### 9.3 前置条件
- **JDK 17+**（`java -version`）。
- **Android SDK**：`Android SDK Platform 35` + `Android SDK Build-Tools 35`。
- 脚本自动查找 `ANDROID_HOME` / `~/AppData/Local/Android/Sdk`。

### 9.4 已踩过的坑（脚本自动处理）
1. **中文工程路径**：AGP 8 默认拒绝。已在 `android/gradle.properties` 加 `android.overridePathCheck=true`。
2. **Gradle 下载慢**：改用镜像（`mirrors.cloud.tencent.com/gradle/`、`mirrors.huaweicloud.com/gradle/`），或手动放进 `~/.gradle/wrapper/dists/`。走代理时给 Gradle 传 `GRADLE_OPTS="-Dhttps.proxyHost=... -Dhttps.proxyPort=..."`。

### 9.5 装到手机
```bash
adb install -r 家庭健康档案-debug.apk
```

## 10. 加密与隐私差异

| 项 | 云端版 | 安卓版 |
|---|---|---|
| 手机号/身份证 | AES-256-GCM | RC4 + 本机密钥（避免明文落盘） |
| 附件上传 | 云存储（临时链接） | 一期未做 |
| 网络 | 微信云 API | 无任何网络调用（飞行模式可用） |
| 备份 | — | 导出 JSON（可选密码 AES-GCM + PBKDF2），含密文需妥善保管 |

## 11. 开发工作流（典型改动）

1. 改云端小程序（页面 / 常量 / 模型 / action）。
2. 在 `apps/miniprogram-app` 跑 `npm run sync`。
3. 回到本工程：`npm run gen:server` + `node scripts/convert-styles.js`。
4. `npm run dev` 预览；`npm run build` 验证。
5. 打包：`npm run apk`。
6. 若只改本工程前端样式/交互（不涉业务逻辑），可直接改 `src/`，但要明白重跑脚本会被云端源覆盖。

---

## 12. 与小程序版的差异（都是单机带来的，不是功能阉割）

| 功能 | 安卓版 |
|---|---|
| 家庭共享 / 邀请码 / 成员审批 | 入口保留，但本机只有一个用户，不会出现待审批 |
| 档案权限（owner/edit/read/none） | 机制完整保留，本机用户对所有档案是 owner |
| 登录 | 无微信身份；可跳过或手机号+密码 |
| 推送提醒 | 一期本就是站内展示，不受影响 |
| 系统字体 / 日期选择 / 安全区 | 跟随安卓系统 |

---

## 13. 合规红线（不可越过）

- **去医疗化**：文案不出现「诊断 / 处方 / 建议服用」。
- **零推送**：提醒仅站内展示。
- **无 AI 诊断**：报告要点为人工标注，不生成自动诊断。
- **数据全本机**：不联网；备份文件含密文，妥善保管。

---

## 14. 常见坑

- 直接改 `src/server/` 或 `src/styles/` → 重跑脚本会被云端源覆盖。改业务逻辑请改云端小程序。
- 改了云端逻辑忘了 `npm run gen:server` → 本工程业务逻辑落后。
- `convert-server.js` / `convert-styles.js` 路径若指向 `apps/miniprogram/`（旧）会 ENOENT → 必须是 `apps/miniprogram-app/`。
- APK 在中文工程路径下报错 → 确认 `android.overridePathCheck=true`。
- Gradle 卡下载 → 换镜像或手动放 dists。
